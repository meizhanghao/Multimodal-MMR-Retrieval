## 2. 投影和温度：应怎样解释

冻结特征后训练独立线性适配层，可以重新加权已有特征并调整跨模态相似度，但无法恢复主干已丢失的细粒度信息。“旋转、缩放”只是直觉：如果两侧施加完全相同的正交旋转，内积保持不变；归一化也会消除统一的正比例缩放。因此不能把任意旋转/缩放等同检索提升。

当前训练使用`exp(logit_scale) * normalize(T) @ normalize(I).T`，对两个方向交叉熵取平均。默认温度可学习，初始`τ=0.07`、`logit_scale≈2.65926`；指数前限制上界，更新后也限制到`log(100)`。该标量不施加weight decay。另提供固定温度开关，方便后续做同条件消融。[CLIP论文2.5节](https://arxiv.org/html/2103.00020v1)、[Chinese-CLIP训练源码](https://github.com/OFA-Sys/Chinese-CLIP/blob/master/cn_clip/training/train.py)给出了相关温度实现依据；本项目不是它们的完整训练复现。

**正标量温度不直接改变固定embedding的余弦Top-K排序。**它通过训练损失影响投影层梯度，才可能间接改变最后的检索效果。线上索引和查询都使用归一化投影特征，分数是余弦，不是正确概率。输出中33个可训练参数仅指4维演示：两个4×4矩阵加1个标量；真实D维同维适配是`2D²+1`。

## 3. HNSW参数和内存：应怎样解释

M控制图的连接规模，efConstruction控制建图探索，efSearch控制查询探索。200主要影响建图工作量和图质量，不宜绝对说它对图结构、临时开销“毫无影响”。[FAISS官方索引说明](https://github.com/facebookresearch/faiss/wiki/Faiss-indexes)列出了参数角色和空间组成；[构造声明](https://github.com/facebookresearch/faiss/blob/main/faiss/IndexHNSW.h)中`IndexHNSWFlat(d, M, metric)`需要显式传M，基础`IndexHNSW`的默认M为32。

例如512维float32，仅原始向量每条就需2048字节，图连接之外还有层级、偏移和分配开销。不能从M=16→32推出整个索引翻倍。本仓库还持有供MMR读取的NumPy向量副本和Python元数据，因此FAISS序列化大小小于完整进程内存，百万级内存必须实际采样。

新增扫描M={16,32}、efSearch={64,128,256}的入口。它能生成真实本机测量，但6条合成数据不足以选择百万级参数；“召回多2～3点”“延迟涨40%”“提升不到1点”等仍需真实评测支持。

## 4. MMR与观测指标

每轮维护候选与已选集合的最大相似度，第一条仍选相关性最高项；后续用新入选向量更新长度N的数组。余弦可为负，不能直接把最大相似度初始化为0。本项目从第一条实际相似度初始化。忽略D时优化后为O(NK)，保留D时为O(NKD)。

`candidate_reduction_ratio = 1 - selected_count/candidate_count`仅记录候选缩减；`pairwise_cosine_reduction`比较“相关性前K条”和“MMR选出的K条”的平均两两余弦，可能为0或负。少于两条时相似度为null。即使相似度下降，也不等于证据覆盖或回答准确率提升；必须同时看相关性和任务标注。当前没有硬去重阈值。

## 5. 服务接口和缓存范围

编码缓存只依赖输入文本和编码模型/投影版本，不依赖索引；当前没有结果缓存。以后添加结果缓存时，键还应包含索引版本、查询、过滤条件、candidate_k、top_k及λ。TTL只控制驻留时间，不能替代版本一致性。

本地图片离线编码已经存在，HTTP暂时只有文本输入；不能声称实现了图像bytes哈希缓存、图像上传或自动托管图片。每个chunk的image_url可能为null，image_reference是上游相对路径标识。

`estimated_total_tokens`按每段UTF-8字节数除4向上取整，只作粗略文本估算；不包含图片、系统Prompt和来源封装。它不是模型tokenizer计数，上层必须用实际生成模型的tokenizer再算预算。

默认10秒是兜底等待时限，不是实测SLA。429表示本进程编码队列饱和，附Retry-After；504表示等待超时；422表示输入不合法。JSON日志包含request_id、query_hash、实际batch_size、排队/编码/总耗时及error_code。模型异常不向外暴露内部堆栈；参数在进入端点前被拒绝时，query_hash和batch_size可能为空。
