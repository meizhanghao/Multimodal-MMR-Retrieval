# 本地验证记录

更新日期：2026-11-12。环境：Windows、Python 3.12.14、CPU。先前初版验证13项测试，本轮实现审核后完整运行结果为**23 passed，0 skipped**（`python -m pytest -q`）。

## 实际验证

- NumPy默认检索、真实FAISS HNSW建库及读写；HNSW参数M=16、efConstruction=200、efSearch=64均能由CLI传入并在HTTP健康接口读回。
- HNSW网格实跑M={16,32}、efSearch={64,128,256}，共6组；结果见[参数扫描](../examples/expected/hnsw_sweep.json)。数据仅6条4维特征，不据此选择生产参数。
- 真实PyTorch训练：可学习温度60步，loss从17.819958降到0.237746；最终logit_scale=2.462037、逆温度=11.728680。这些是本次合成输入的观察值，不是材料中声称的领域实验。
- 固定温度对照同样实际运行60步；温度始终约0.07。学习/固定两条路径分别为33/32个可训练参数，只用于验证训练方式；未计算独立测试集Recall或温度带来多少提升。
- 训练出的新checkpoint实际用于重新建库并查询；测试还覆盖旧checkpoint、旧manifest和v2索引版本校验。
- 实际启动Uvicorn子进程，经localhost HTTP运行`/health`、`/v1/retrieve`和`/encode`，验证服务默认参数、来源、版本与编码缓存命中。进程在验证后已关闭。
- 测试覆盖有界合批、版本键、TTL到期、LRU容量、缓存副本隔离、429、检索阶段10秒等待机制（测试用缩短时限）、参数422与不记录原始查询的JSON日志。
- MMR仍用100组随机输入对照独立逐轮实现；新增检查证明候选缩减50%时，冗余改善仍可能为0，不把它当成去重率。

## 本次CLI命令

```text
python -m mmclip demo --out runs/review-default
python -m mmclip build --backend faiss --kind hnsw --hnsw-m 16 --ef-construction 200 --ef-search 64 --out runs/review-index
python -m mmclip search --index runs/review-index
python -m mmclip train --steps 60 --temperature 0.07 --max-logit-scale 100 --out runs/review-learned
python -m mmclip train --steps 60 --temperature 0.07 --max-logit-scale 100 --out runs/review-fixed --fixed-temperature
python -m mmclip build --backend faiss --projection runs/review-learned/projection.pt --out runs/review-projected
python -m mmclip search --index runs/review-projected --projection runs/review-learned/projection.pt
python -m mmclip evaluate
python -m mmclip evaluate --sweep --m-values 16 32 --ef-values 64 128 256
python -m mmclip serve --index runs/review-index --port 58441 --queue-capacity 128 --max-batch 16 --max-delay-ms 5 --cache-size 128 --cache-ttl-seconds 3600 --request-timeout-seconds 10
```

服务命令中的端口为本次自动分配；手动操作使用教程8001即可。其余命令退出码均为0。服务API返回见[retrieve.json](../examples/expected/retrieve.json)，训练轨迹见[学习温度](../examples/expected/training_learned.json)和[固定温度](../examples/expected/training_fixed.json)。

## 实际范围

已运行的是真实FAISS、PyTorch、FastAPI和Uvicorn，输入仍为合成数据/理想特征。没有运行Chinese-CLIP权重、领域测试集、百万级索引、GPU压测、图像HTTP上传或上层LLM集成。材料中的62%→71%、3个百分点消融和40%延迟变化没有本地实验证据。

`estimated_total_tokens`只是UTF-8字节启发式估算。索引字节数不是整个进程内存，MMR平均余弦变化也不是事实正确率。每个指标的解释见[实现审核](04_实现细节审核与参数同步.md)。
