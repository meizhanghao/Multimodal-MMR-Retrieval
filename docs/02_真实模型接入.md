# 从理想上游输入切换到真实Chinese-CLIP

以下命令在仓库根目录执行，`$projectPython` 是README里创建的虚拟环境解释器。

## 第一步：只替换确定的向量

先复制 `examples/pairs.json` 和 `features.json` 理解ID顺序，再通过Python直接调用 `VectorIndex(vectors, items, encoder='your-model:revision:projection')`。如果已有上游特征，这一步不需要Chinese-CLIP。

输入必须是同一表示空间：查询、图像库与投影头的维度一致，模型版本一致。不能将4维演示索引与真实模型向量混用。

## 第二步：替换实际图文样本

在配对清单中填入真实 `text`、`image`、来源文档与段落ID；图片路径相对于清单所在目录。示例的几何图可验证文件读取，不适合证明图文检索质量。

```powershell
& $projectPython -m pip install -e '.[models,faiss,train]'
& $projectPython -m mmclip export-features --pairs examples/pairs.json --device cpu --out runs/real-features.json
& $projectPython -m mmclip train --features runs/real-features.json --steps 60 --out runs/real-train
```

`cn_clip` 的模型名写作 `ViT-B-16`，对应简历中的ViT-B/16。默认下载目录是 `models/`。GPU需要安装匹配的Torch/Torchvision并将设备改成 `cuda`；安装匹配方式以PyTorch官方包为准。

本次没有运行权重下载，上述接入路径待真实环境验证。遇到下载、算子或版本错误时先单独执行 `ChineseCLIPEncoder.encode` 检查两种模态的形状，不要直接改MMR规避问题。

## 第三步：用投影后的同一空间重建索引

```powershell
& $projectPython -m mmclip build --pairs examples/pairs.json --encoder chinese-clip --projection runs/real-train/projection.pt --backend faiss --kind flat --out runs/real-index
& $projectPython -m mmclip search --index runs/real-index --encoder chinese-clip --projection runs/real-train/projection.pt --query '医院设备采购'
& $projectPython -m mmclip serve --index runs/real-index --encoder chinese-clip --projection runs/real-train/projection.pt --port 8001
```

不使用投影头时，两边都去掉 `--projection`。不要只给图像向量加投影、查询仍用原始空间。更换投影文件将改变编码指纹，旧索引会被拒绝。

输入的特征JSON包含特征、ID、合成标记和编码指纹；训练报告另保存实际参数和温度轨迹。真实实验还应在旁边保存样本分组、原始文件哈希和训练/验证划分；相同文档的近重复图片不要跨集合。

## 接口替换表

| 已有上游能力 | 对接位置 | 需要保证 |
|---|---|---|
| 已有图像/文本向量 | `VectorIndex`、`search_vector` | N×D、相同编码空间、稳定ID |
| 已有编码服务 | 实现`encode(inputs, modality)`和`fingerprint` | 返回顺序、超时、错误、版本 |
| 已有领域图文配对 | `load_pairs`输入清单 | 来源追踪、合法图片、可靠配对 |
| 已有上层问答系统 | 调用HTTP `/search` | 用`source/doc_id`引用，不把分数当概率 |
| 已有原文存储 | `/documents/{id}`的读取函数 | 当前实现只读清单元数据，真实原文需另接 |

首次集成先跑1条，再跑批量；保留输入与原始输出，确认维度、顺序和来源后再测性能。

当前适配层加在原Chinese-CLIP完整encode输出之后；这与解冻其原生text_projection/visual.proj不同。要更换训练位置，需一并修改特征导出、checkpoint格式和在线查询编码，不能只改面试描述。[审核说明](04_实现细节审核与参数同步.md)提供了准确表述。
