# 逐文件阅读与输入输出

## 先跑最短的数据流

`examples/features.json` 提供 `image_features: N×D` 和查询特征；`pairs.json` 提供相同顺序的N条记录。`VectorIndex` 归一化后计算余弦近邻，`RetrievalPipeline` 取候选，`mmr` 返回候选矩阵中的行号，最后将行号映射回文档、段落和图片。

不要将FAISS行号当业务ID：行号只对当前索引有效；输出和上层调用使用 `id/doc_id/paragraph_id/source`。

| 文件/入口 | 输入 | 输出/职责 | 替换或失败边界 |
|---|---|---|---|
| `data.load_pairs` | JSON路径、是否检查图片 | `(valid, rejected)`；附解析后图片路径 | 缺字段、重复ID和缺图保留拒绝原因 |
| `data.torch_dataset` | 合法配对与模型预处理函数 | Dataset；每条为ID、文本、图像Tensor | 由DataLoader决定批量；不在读取时默默换图 |
| `FixtureEncoder.encode` | 已知文本或样例图片文件名 | `float32[B,4]` 单位向量 | 仅查固定表，未知输入报错 |
| `ChineseCLIPEncoder.encode` | 文本列表或本地图片路径列表 | `float32[B,D]` | 主干eval且不求梯度；首次显式调用才取权重 |
| `features.export_features` | 配对清单、真实编码器 | IDs及两组`N×D`特征JSON | `shuffle=False`保持对齐；训练只消费冻结特征 |
| `DualProjection.forward` | 两组`Tensor[B,D]` | 投影并归一化的文本/图像特征 | 两个新增Linear层，另有默认可学习的logit_scale标量 |
| `symmetric_infonce` | 对齐特征和正温度/可学习的正缩放标量 | 标量loss | 少于2对样本、非有限值/零特征报错 |
| `VectorIndex.search` | 查询`D`维、k、过滤条件 | `(row, cosine_score)`列表 | 大k截到实际数量；过滤路径使用精确预过滤 |
| `VectorIndex.save/load` | 索引目录/预期编码版本 | JSON、NPY、可选FAISS文件 | 编码器、维度、总数或v2快照版本不匹配时报错 |
| `vectors.mmr` | 查询、`N×D`候选、k、λ | 不重复行号列表 | 空候选返回空；按原候选顺序打破平局 |
| `BatchEncoder.encode` | 一段文本、请求超时 | 对应向量 | 等待时间包含排队；取消请求不再写回Future |
| `api.create_app` | 已建索引、匹配编码器 | FastAPI实例 | 生命周期创建/关闭worker；不额外下载权重 |
| `evaluate.evaluate` | 特征、查询、k | ANN Recall、延迟、索引大小 | 只评近邻搜索，不评人类语义相关性 |

## InfoNCE如何使用

`logits = exp(logit_scale) * normalize(T) @ normalize(I).T`，其中`logit_scale=log(1/τ)`。支持固定τ，默认τ初始0.07且可学习；缩放上限100，训练报告保留每步温度。标签是批内对角线位置，文本到图像与图像到文本交叉熵取平均。

`train_features` 从特征JSON创建 `TensorDataset/DataLoader`，训练新增的投影头与默认可学习温度，保存 `projection.pt` 和逐步loss。编码主干不在优化器中；真实特征通过 `features.py` 的 `inference_mode()` 离线计算。当前没有训练整座Chinese-CLIP，也没有大模型预训练。

每一对图文需要可靠配对。两张图实际表达相同内容时，批内其他项可能是假负例；本初版未实现多正样本损失，真实数据应先分组去重并做消融。

## MMR增量更新为何成立

首项选择相关性最高的候选。之后选择：

`lambda * relevance(i) - (1-lambda) * max(sim(i, j) for j in selected)`。

每次选入新项，只计算它与所有候选的相似度，更新长度N的最大相似度数组。选K项约需 `O(NKD)`，额外数组约 `O(N)`，没有预存 `N×N` 矩阵。负相似度按原值保留，初始化为0会改变算法。

MMR不是硬去重，也不保证每一项相关：候选质量差或λ太小会选入无关但不同的资料。应先用召回和业务过滤保证候选质量，再比较λ的实际收益。

## 批量队列与缓存

`BatchEncoder` 有界队列默认128，最多16条组成一批，最长合批等待5ms。缓存为最多128项的LRU+3600秒TTL。同步编码进入 `asyncio.to_thread`；结果按批内原顺序对应各请求。缓存键为“编码版本+文本SHA-256”，缓存的是编码，不是完整检索结果，因此索引变化不需要清除编码缓存；模型或投影变化必须换编码版本。

该限额只在单个进程中生效；多worker会分别加载模型和队列。超时取消本地等待不会强行终止已开始的线程/GPU计算，结果不会交给已取消请求。关闭时等待现有任务完成，再退出worker。

索引目前不可在线写入；文档更新后重建新目录并切换服务。持久化格式供本地可信文件使用，不接受远程用户上传FAISS文件。
